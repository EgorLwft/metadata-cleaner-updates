# Пересборка MetadataCleaner с заменённой библиотекой

Комплект предназначен для получателя Windows-версии MetadataCleaner 1.4. Он
содержит клиентскую программу в форме объектного кода Python (`objects/*.pyc`),
небольшой открытый загрузчик, скрипт сборки, ресурсы, уведомления и исходники
указанных сторонних библиотек. Исходники интерфейса, инструменты владельца и
закрытый ключ подписи разрешений в комплект не входят. Файлы `.pyc` позволяют
выполнить пересборку и доступны для технического анализа; они не являются
средством сокрытия секретов.

## Получателю: обычная пересборка

1. Распакуйте ZIP в отдельную папку. Используйте Windows x64 и CPython той же
   основной и дополнительной версии и разрядности, которые указаны в
   `relink-manifest.json` (для первой сборки: CPython 3.12 x64). Виртуальное
   окружение отделяет ваши изменения библиотек от установленной программы.
2. Откройте PowerShell в распакованной папке и выполните:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
   .\.venv\Scripts\python.exe rebuild_from_objects.py --check-only
   .\.venv\Scripts\python.exe rebuild_from_objects.py
   ```

3. Результат находится в `rebuilt`, журнал PyInstaller — в
   `rebuild-work\pyinstaller.log`. Для повторного запуска укажите новые каталоги:

   ```powershell
   .\.venv\Scripts\python.exe rebuild_from_objects.py --output rebuilt-2 --work rebuild-work-2
   ```

Программа устанавливает библиотеки только по вашей команде `pip`; скрипт
пересборки ничего не скачивает и не удаляет прежние сборки. `pytest` и
`reportlab` из зафиксированного окружения использовались разработчиком для
проверок: пересборка не требует их наличия. PyInstaller анализирует инструкции
импорта в объектных `.pyc`; исходники клиентских модулей ему не требуются.

## Замена lxml / libiconv и других библиотек

Объектный код программы не связан с конкретным хешем `lxml.etree.pyd`.
До запуска пересборки установите свою совместимую сборку lxml в отдельное
окружение. Если libiconv статически включена в lxml, её меняют при сборке lxml
и её нативных зависимостей, затем устанавливают полученный wheel:

```powershell
.\.venv\Scripts\python.exe -m pip install --force-reinstall --no-deps C:\MyBuild\lxml-custom.whl
.\.venv\Scripts\python.exe rebuild_from_objects.py --output rebuilt-custom --work work-custom
```

Путь wheel в примере нужно заменить настоящим именем файла wheel. Исходники
для этого находятся в `compliance\sources`: lxml, pikepdf и зафиксированные
проекты сборки libiconv/libxml2/libxslt/zlib. Контрольные суммы исходных архивов
приведены в `relink-manifest.json`, сведения о происхождении — в
`compliance\native-sources.json`. Файлы сборки стороннего проекта содержат
собственные требования к C/C++ инструментам и дополнительным исходникам.
Наличие этих архивов само по себе не доказывает воспроизводимость нативного
бинарного файла: перед публикацией разработчик отдельно проверяет полноту
соответствующих исходников и возможность замены библиотеки.

Если вы сознательно заменили библиотеку другой версией, добавьте
`--allow-library-versions`. При сознательном изменении ресурсов или объектов
комплекта добавьте `--allow-kit-changes`. Эти опции отключают проверки
соответствия исходному комплекту, сохраняя проверку совместимости Python.
Они не требуют разрешения сервера или подписи владельца. Нельзя менять только
четырёхбайтный заголовок `.pyc` для другой версии Python: нужен совместимый
комплект объектных файлов.

Собственная лицензия программы должна разрешать изменения для собственного
использования и обратный анализ для отладки таких изменений в объёме,
необходимом LGPL. Права на сторонние компоненты определяются их лицензиями
в `compliance\licenses`, а не запретами собственной лицензии приложения.
Разрешение на компьютер/флешку должно продолжать действовать на том же носителе
после замены библиотеки и пересборки: контроль хеша EXE или запрет запуска
изменённой LGPL-библиотеки с этим механизмом несовместимы. Ключ владельца для
такой пересборки и её запуска не нужен. Изменённый EXE следует проверять
локально; он не должен выдаваться за неизменённую официальную сборку.

## Разработчику: подготовка комплекта

Эта часть относится к закрытому рабочему репозиторию. Сначала подготовьте
новую версию, действующие `LICENSE.txt` и уведомления, полный lock-файл,
`licensing\public_key.json`, клиентский `updater.py` и очищенный от optional
Math::BigInt::GMP runtime в `build\vendor-exiftool`. Не используйте старый
`vendor\exiftool` версии 1.3.

```powershell
.\.venv\Scripts\python.exe tools\make_relink_kit.py --version 1.4.0 --vendor-root build\vendor-exiftool --output release\MetadataCleaner-1.4-relink-kit.zip
```

Экспорт использует белый список: app, cleaner_core, ui_design, metadata_view,
network_paths, windows_shell, activation_ui, updater, update_ui и четыре клиентских
модуля licensing. Для них создаются `.pyc` в старой схеме расположения
(`objects\app.pyc`, `objects\licensing\__init__.pyc` и т. д.), без собственных
`.py` и без абсолютного пути разработчика в `co_filename`. Закрытые инструменты,
личные настройки, документы, журналы, лицензии пользователей и ключи
подписания не экспортируются. Из каталога исходников сторонних библиотек
берутся только семь явно названных архивов lxml/pikepdf/native build projects;
исходники Pillow и прочие необязательные архивы не добавляются.

До публикации распакуйте ZIP вне закрытого репозитория, пересоберите из него
EXE и проверьте очистку синтетических PDF/Office/изображений, работу сети,
просмотр аудио, обработку видео, активацию и запуск с заменённой lxml на уже
разрешённом компьютере. Проверяйте итоговый состав PyInstaller (`BINARY` и
`EXTENSION`) и соответствие уведомлений фактическим зависимостям.

Комплект должен лежать рядом с **соответствующим** EXE в том же релизе и быть
доступным всем его получателям без дополнительной платы. Ссылка только на
исходники upstream или только на `.pyc` без работающей пересборки не заменяет
обязательства LGPL. Окончательное заключение о соблюдении зависит от
фактического бинарного состава и работоспособности замены, а не от наличия
этого документа.
