# Metadata Cleaner — канал обновлений

Переносимая Windows x64 программа для проверки и очистки поддерживаемых метаданных документов.
Для запуска требуется активация на компьютере или USB-носителе. В версии 1.5
сервер выдаёт бесплатное подписанное разрешение на календарный год; после
окончания срока активацию можно повторить. Прежние разрешения владельца действуют.

Скачайте **EXE и соответствующий relink-kit ZIP из одного Releases**. Сохраняйте комплект
при передаче другому человеку. ZIP содержит лицензии, соответствующие исходники сторонних
библиотек, объектные модули клиента и инструкции замены библиотек и пересборки.
Для обычного запуска установленный Python и Office не нужны.

Собственная охраняемая часть предоставляется по индивидуальной proprietary-лицензии
LicenseRef-MetadataCleaner-Proprietary; сторонние компоненты сохраняют свои лицензии.
Публичная доступность загрузки сама по себе не даёт разрешения на эксплуатацию собственной части.

channel.json подписан Ed25519. Открытый ключ закреплён в приложении; программа проверяет
подпись, версию, источник, размер и SHA-256 перед заменой EXE с резервной копией.
Проверка версии выполняется в фоне при запуске. Настройка автоматической загрузки и
установки доступна в меню настроек; офлайн-работа после активации поддерживается.
